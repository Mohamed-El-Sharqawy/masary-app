Masary — UI/UX Plan

How the app looks and how you operate it · vibrant, saturated & flat · Arabic (فصيح) UI, RTL · React Native + Expo + NativeWind

Status: v1.3 — all decisions locked (Flamingo chosen) Companion to: docs/technical-plan.html (v1.3) Date: 2026-08-24
Final round — decisions locked: design direction C — "Flamingo" (flat coral + magenta on rose cream) · numerals Western 0-9 default with Eastern toggle · theme follow system + in-app toggle · onboarding one 3-screen intro (value · voice demo · privacy) · icons clarified: functional icons (send, microphone) used normally; the logo is an image the captain will provide — plain text "مصاري" as the placeholder until then.

1 · Design principles

  • Vibrant & saturated — bold color is the brand; money apps are usually conservative navy/blue, so saturation is differentiation (research: nobody in the category is colorful).
  • Flat & confident — no gradients, no AI slop (captain rule): solid saturated color blocks only; no gradient heroes or CTAs, no glassmorphism, no purple-blue AI clichés.
  • UI copy in Modern Standard Arabic (فصيح) (captain rule): MSA for readability, translation, and app convention; user input stays welcome in Egyptian dialect, MSA, English, or mixed — understanding all of them is the app's job.
  • Icons: functional & contrast-safe (captain rule): normal icon usage for functional actions (send, microphone); no icon-based logo — the logo is an image the captain provides (text "مصاري" placeholder); icons never in a color close to the surface behind them.
  • Arabic-first, RTL by default — mirrored layout, Arabic typography primary, English toggle; mixed content must look natural in one conversation.
  • Chat is home — the app opens directly into the conversation; logging an expense is one message away, never a form.
  • Thumb-first — composer and mic within thumb reach; destructive actions away from the thumb arc.
  • Calm data, loud actions — saturated color on primary actions, category chips, and charts; surfaces stay readable so numbers stay trustworthy.
  • Fast feels fast — every AI wait has an immediate optimistic state ("جاري الحفظ…"); confirmations use haptics + color, never blocking spinners alone.

2 · Design directions — pick one

Option A — "Marigold" light-first

Sun-warm and citrusy. Warm paper canvas, one flat vivid marigold orange as the hero color, amber energy accents, teal for money-positive. The friendliest, most daylight-Egyptian feel — zero gradients anywhere.

Warm paper#FFFBEB · bg
Marigold#EA580C · primary
Amber#F59E0B · accent
Teal#0D9488 · success/income
White#FFFFFF · surface
  • Feel: bright, optimistic, approachable — reads "lifestyle utility", not "bank".
  • Charts: orange → amber → coral → teal ramp; teal marks income, deepest orange flags overspend.
  • Tradeoffs: orange pushes warmth over "serious money"; destructive red stays clearly separate (#DC2626, destructive actions only).
  • Risk: amber on white fails small-text contrast — amber is for fills and graphics, never body text.

5 · UX flows

١ · First launch → in the app (target: under 20 seconds)
شاشة الترحيب (سطور تعريفية قصيرة)→إنشاء حساب→البريد / OAuth→محادثة فارغة مع أمثلة جاهزة
أو→الدخول كضيف→مباشرة إلى المحادثة (بلا نماذج)→شريط: "بياناتك محفوظة على جهازك فقط"
٢ · Log an expense by text (the core loop)
اكتب "شريت قهوة وميترو بـ 35"→إرسال→"جاري الحفظ…" (فوري)→بطاقات التأكيد→تأكيد (اهتزاز خفيف) — تم التخزين
٢ب · Smart multi-item — ask, never guess the split
"شريت قهوة وميترو بـ 35" (مجموع فقط)→المساعد: "بكم القهوة؟ وبكم المواصلات؟"→"القهوة 20 والميترو 15"→بطاقتا تأكيد
٣ · Log by voice (optional path)
اضغط زر التسجيل→موجة صوتية حية→اضغط للإيقاف (حد 30 ثانية)→فقاعة النص المتحوَّل→بطاقات التأكيد
٤ · Ambiguity → clarification (never a silent guess)
"شريت قهوة"→المساعد: "كم المبلغ؟"→"20"→بطاقة تأكيد
٥ · Ask about spending
"كام صرفت على القهوة الشهر ده؟" (لهجتك المحلية مرحّب بها)→بطاقة إجابة: "أنفقت 460 ج.م على 23 قهوة هذا الشهر" + رسم مصغر→اضغط ← قائمة الحركات المفلترة
٦ · Guest → account upgrade (data never lost)
الإعدادات: "أنشئ حسابًا واحفظ بياناتك"→تسجيل→دمج لمرة واحدة: رفع السجل المحلي إلى السحابة→"تم! تتم مزامنة بياناتك الآن ✓"
٧ · Same account, second device
تسجيل الدخول على هاتف جديد→مزامنة كاملة (سحب السجل)→نفس البيانات ونفس اللوحة
٨ · Offline
لا يوجد اتصال→شريط: "سيتم الحفظ دون اتصال — وتتم المزامنة عند عودة الإنترنت"→النصوص والمقاطع الصوتية في قائمة انتظار→عودة الشبكة ← مزامنة تلقائية
٩ · Backup & import (works for guests too)
الإعدادات ← النسخ الاحتياطي→تصدير masary-backup-2026-08-24.json→على أي هاتف: استيراد ← استعادة كاملة

7 · Micro-interactions & feedback

  • Entrance scale (captain spec): any container entering with text + an icon scales 0.9 → 1 (0.95 for large cards) with a fade — confirm cards, chip rows, answer cards.
  • Confirm haptic (light) when a transaction stores; success color pulse on the card border.
  • Card entrance: confirm cards slide up + fade (180 ms); multi-item stacks stagger 60 ms.
  • Waveform animates live while recording; on stop it morphs into the "جاري الحفظ…" bubble.
  • Optimistic states: user bubble appears instantly; assistant placeholder shimmer never blocks input.
  • Sync badge: tiny indicator on chat header while the queue drains; turns ✓ with a subtle pop.
  • Overspend cue: dashboard month bar in accent color when > budget (post-M5 budgets).
  • RTL motion: all slide/fade directions mirror in Arabic; nothing LTR-locked.
